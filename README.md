# Piano-K Website

This folder contains the complete static website for GitHub Pages.

Upload these items to the root of the public `piano-k-app` repository:

- `index.html`
- `styles.css`
- `privacy/`
- `support/`
- `images/`
- `CNAME`
- `.nojekyll`

After uploading, enable GitHub Pages from the `main` branch and `/ (root)`.
